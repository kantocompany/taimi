Key observations

  • OpenAI Codex Go ($8/mo, platformP) is the cheapest paid subscription; GitHub Copilot Pro ($10/mo) is the cheapest standalone individual plan. Mistral Vibe ($14.99/mo) is the only EU-headquartered vendor — critical for data sovereignty.
  • Team seat costs range ~6.6× from $19 (Copilot Business) to $125 (Claude Code Premium Seat); Kiro dropped its team tiers entirely (2026-08-30), leaving Enterprise as its only multi-seat option.
  • Usage-based is apples to oranges: Copilot moved to AI Credits (token-based, $0.01/credit) June 2026 — previously per request ($0.04). Anthropic/OpenAI/Mistral charge per token, Devin per ACU, Replit per effort-based Agent task. Cursor dropped explicit overage — usage scales with plan tier (3×/20×).
  • Mistral's Devstral 2 output tokens ($2.00/M) are ~12× cheaper than Claude Opus 5 output ($25/M). Claude Sonnet 5 ($10/M output) sits between — the scheduled 2026-09-01 increase to $15/M was cancelled, making the introductory rate permanent.
  • Platform bundlingP: Claude Code, Codex, Vibe, and Devin subscription plans include their full platforms (Claude.ai, ChatGPT, Le Chat, and — since Cognition folded Windsurf into Devin Desktop in June 2026 — the Devin Desktop IDE). Their prices aren't directly comparable to standalone tools like Cursor, Kiro, or Google Antigravity (agent-first IDE, Free–$100/mo; replaced Gemini Code Assist as Google's primary developer tool at Google I/O 2026).
  • Self-hosted / on-prem: Mistral (EU data, fine-tune), Cline (open-source BYOK). Kiro (AWS) is the only AWS-native tool — spec-driven IDE with hooks and steering files; Pro at $20/user. Replaces Amazon Q Developer (EoS April 2027).
  • No SWE-bench scores here, on purpose. Vendor publications are self-reported with cherry-picked configurations, the official leaderboard doesn't cover consumer agent products (it ranks model+scaffold combos), and variants (Verified, Pro, Lite) aren't comparable. Showing a single number next to "—" would imply a ranking the data can't support.
