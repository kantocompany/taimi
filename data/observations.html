Key observations

  • OpenAI Codex Go ($8/mo, platformP) is the cheapest paid subscription; GitHub Copilot Pro ($10/mo) is the cheapest standalone individual plan. Mistral Vibe ($14.99/mo) is the only EU-headquartered vendor — critical for data sovereignty.
  • Team seat costs range 10× from $19 (Copilot Business) to $200 (Augment Max).
  • Usage-based is apples to oranges: Copilot moves to AI Credits (token-based, $0.01/credit) June 2026 — previously per request ($0.04). Anthropic/OpenAI/Mistral charge per token, Devin per ACU, Replit per effort-based Agent task. Cursor dropped explicit overage — usage scales with plan tier (3×/20×).
  • Mistral's Devstral 2 output tokens ($2.00/M) are ~12× cheaper than Claude Opus 4.7 output ($25/M). Sonnet 4.6 ($15/M) sits between.
  • Platform bundlingP: Claude Code, Codex, and Vibe subscription plans include their full platforms (Claude.ai, ChatGPT, Le Chat). Their prices aren't directly comparable to standalone tools like Cursor, Windsurf, or Gemini Code Assist (free individual tier, 6K completions/day).
  • Self-hosted / on-prem: Windsurf (FedRAMP), Mistral (EU data, fine-tune), Cline (open-source BYOK). Kiro (AWS) is the only AWS-native tool — spec-driven IDE with hooks and steering files; Pro at $20/user. Replaces Amazon Q Developer (EoS April 2027).
  • No SWE-bench scores here, on purpose. Vendor publications are self-reported with cherry-picked configurations, the official leaderboard doesn't cover consumer agent products (it ranks model+scaffold combos), and variants (Verified, Pro, Lite) aren't comparable. Showing a single number next to "—" would imply a ranking the data can't support.
